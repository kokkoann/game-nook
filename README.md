# Game Nook 🎮
A cozy web collection of simple browser 2D games like Snake, Minesweeper, and more.

## Features (Planned)
- Snake Game
- Minesweeper
- Solitaire

## Tech Stack
- HTML, CSS, JavaScript.
- AWS hosting (future).

## Status
🚧 In development

## Why JS games?
I'm a videogame enthusiast but i don't really know how to make my own videogame. I dream of making a living from videogame dev so i think starting my journey with basics is a great step in the right direction ;]
